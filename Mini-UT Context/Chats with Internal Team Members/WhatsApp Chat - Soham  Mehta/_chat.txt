[11/09/25, 7:17:04 PM] Soham  Mehta: Enhancements to Make Explicit
1. AI-Native Design Patterns
    * Principles of conversational UX (e.g., context persistence, turn-taking, error recovery).

    * Patterns that leverage AI capabilities (summarization, personalization, prediction, multimodality).

    * Contrast with traditional UI (forms, menus, deterministic flows).

    * Case studies: Slack AI search vs. traditional filters, Copilot autocomplete vs. dropdown menus.

2. Deterministic vs. Non-Deterministic UX Decisions
    * Framework: “When to Automate, When to Ask.”

    * Deterministic flows (e.g., booking, payments) vs. probabilistic AI suggestions (e.g., drafting, prioritization).

    * Guardrails: user overrides, confirmation steps, undo patterns.

    * Example: Gmail autocomplete (AI decides suggestion) vs. checkout (user confirms every step).

3. When to Use Agents vs. Conversational UX vs. Generative Content
    * Agents: continuous, goal-driven (e.g., scheduling across multiple systems).

    * Conversational UX: task guidance, clarifying intent (e.g., customer support bots).

    * Generative Content: creation, inspiration, personalization at scale (e.g., marketing copy, imagery).

    * Decision matrix: matching user goal, complexity, and system autonomy.

4. Interaction Reliability Patterns
    * Designing for AI confidence: show certainty indicators, ranked options, or “best guess + alternatives.”

    * Graceful failure strategies: fallback to rules, human handoff, or “I don’t know” responses.

    * Progressive disclosure: let AI act when confidence is high, otherwise invite user confirmation.
